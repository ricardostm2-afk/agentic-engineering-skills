Predict the effect of a wait

A prediction is clearer when you change one cause and observe the result. This interaction uses wait duration as the causal variable.

First choose a hypothesis. Then run the case, compare what happened, and read the feedback about the changed condition.

Prediction and observation

If the wait exceeds the limit, the request is rejected. If it is equal to or below the limit, the request is accepted. Move the variable, predict the branch, and test it.

The interaction did not open. Use the rule above and compare a short-wait case with a long-wait case.

Transfer

Invent a different limit and explain why the same request can change result when duration changes. The variable is the cause; feedback should mention the condition. Try first; then open the answer and rubric to check your reasoning.

Reference answer and rubric

One valid answer chooses limit 50: with duration 60, duration is above 50 and the request is rejected; with duration 50, it equals the limit and is accepted. Another limit is valid if you apply the same rule to the chosen case.

  • Identify duration and limit as the two conditions you are comparing.
  • Apply “above” for rejection and “equal or below” for acceptance.
  • Explain that changing the limit or duration changes the outcome because it changes the condition.
